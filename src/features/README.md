# Features

The `features` layer (FSD): user scenarios (actions on data).

Planned features:

- `add-feed` — add a feed by direct RSS URL;
- `refresh-feeds` — refresh feeds (fetch, upsert articles, 50-non-saved retention);
- `translate-article` — translate an article via the chosen AI provider (BYOK);
- `manage-providers` — configure AI providers: preset, model, API key (expo-secure-store), translation language.
