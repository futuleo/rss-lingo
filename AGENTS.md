# Agent guidance

- **Language policy (strict): all code, comments, commit messages, README files, and docs in this repository must be written in English only.** The only exceptions are i18n translation resources (e.g. `src/shared/i18n/locales/ru.json`) which contain user-facing translations by design. Never introduce non-English text into code, comments, docs, or commit messages.
- **Commit discipline (strict): commit early and often. Never accumulate uncommitted work — a checkpoint commit every time ~10 files are touched, and always commit before finishing a task.** Never report a completed milestone without its commits landed. Use `wip(scope): ...` checkpoint commits for in-progress states; rewrite nothing.
- **Git workflow (strict): work on a dedicated feature branch, never directly on `main`.** Create a branch per work item (`git checkout -b <scope>/<short-name>`), commit each meaningful stage there, and merge into `main` once the work is complete, reviewed, and all checks pass. Push to `origin` only when the user explicitly asks.
- This repository is a React Native + Expo app: sources in `src/` (features/entities/widgets/pages/shared) and routes in `app/` (expo-router). Checks: `npm run typecheck`, `npm run lint`, `npm test`. Verify a command exists before assuming others.
- `.opencode/opencode.jsonc` selects the `orchestrator`; agent roles and their workflow are defined in `.opencode/agents/`. Keep these as the source of truth for agent-specific behavior.
- The configured default model is `deepseek/deepseek-v4-pro`; agents use `deepseek/deepseek-v4-pro` for reasoning-heavy roles and `deepseek/deepseek-flash` for routine work. Do not switch providers/models or enable pay-as-you-go without user approval. Follow the one-time escalation limits in the agent profiles.
- Keep changes focused. Ask before destructive or hard-to-reverse actions, publishing/deploying, or changing credentials; push to `origin` only when explicitly asked.
